# 🚗 Vehicle Service Record System

A Python-based Vehicle Service Record Management System designed to manage and maintain vehicle service information efficiently.

## 📌 Project Overview

The **Vehicle Service Record System** is a console-based Python application that helps users manage vehicle service records.

The system allows users to add, view, search, update, and delete vehicle service records. It uses **Object-Oriented Programming (OOP)** concepts and file handling to store and manage records.

## ✨ Features

- ➕ Add new vehicle service records
- 📋 View all service records
- 🔍 Search vehicle/service records
- ✏️ Update existing records
- 🗑️ Delete records
- 💾 Store and retrieve records using file handling
- ✅ Input validation
- 🚘 Manage vehicle service information through a simple console interface

## 🛠️ Technologies Used

- **Python**
- **Object-Oriented Programming (OOP)**
- **File Handling**
- **CRUD Operations**
- **Input Validation**
